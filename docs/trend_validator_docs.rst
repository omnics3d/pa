===============================================================================
Техническая спецификация отчета Trend Validator (v2026_2)
===============================================================================

.. meta::
   :description: Описание математической модели анализа последовательностей.
   :keywords: алгоритм, статистика, вероятности, трейдинг 2026, таймфрейм

Данный документ является руководством по интерпретации данных CSV-отчета,
формируемого модулем ``trend_validator.py``.

Блок 1: Метаданные сегмента
===========================

.. glossary::

   file
      **Идентификатор таймфрейма.** Указывает на конкретный временной интервал
      или индекс исторического блока данных (например, 5-минутный отрезок).
      Позволяет локализовать аномалии на временной шкале.
   
   candles
      Общее количество свечей (N) внутри данного таймфрейма. Является
      **базисом расчета**. Все параметры с суффиксом ``_%`` в группах
      f2-f6 вычисляются относительно этого числа.

Блок 2: Динамика инициативы (Развороты)
=======================================

Анализ момента, когда одна сторона ломает тренд противоположной стороны.

.. list-table:: Метрики инициации
   :widths: 15 85
   :header-rows: 1

   * - Поле
     - Алгоритмический смысл и торговая интерпретация
   * - **ch_t**
     - **Change Total.** Общее кол-во точек смены цвета (разворотов).
   * - **ch_%**
     - **Индекс шума.** Доля разворотов в общем объеме свечей.
       Порог: >45% — фаза "распила", тренды неэффективны.
   * - **ch_g / ch_r**
     - Чистая частота атак. Сколько раз покупатели (green) или
       продавцы (red) успешно изменили цвет свечи.
   * - **ch_g_%**
     - **Бычья инициатива.** Доля зеленых разворотов от ``ch_t``.
       Если >60%, покупатели агрессивно доминируют в атаках.
   * - **ch_r_%**
     - **Медвежья инициатива.** Доля красных разворотов от ``ch_t``.
       Если >60%, продавцы оказывают доминирующее давление.

Блок 3: Математическое ожидание (Условные вероятности)
======================================================

Показывает "выживаемость" тренда при переходе с уровня на уровень.

.. note::
   Сумма ``pX_c`` (продолжение) и ``pX_r`` (разворот) всегда равна 100.0%.

* **p1_c / p1_r (1 -> 2):** Шанс подтверждения разворота 2-й свечой.
  Если ``p1_r > 50%``, большинство входов на первой свече — ложные.
* **p2_c / p2_r (2 -> 3):** Зона подтверждения микро-тренда.
  Если ``p2_r`` высок, рынок склонен к формированию "двойняшек".
* **p3_c / p3_r (3 -> 4):** Точка инерции. Если свеча закрылась 3-й раз,
  вероятность 4-й свечи обычно статистически максимальна.
* **p4_c / p4_r (4 -> 5):** Стадия зрелости тренда. Оценка усталости.
* **p5_c / p5_r (5 -> 6):** Предел тренда. Резкий рост ``p5_r`` указывает
  на математический потолок движения для данного таймфрейма.

Блок 4: Статистика уровней глубины (f2 - f6)
============================================

Качественная "выносливость" сторон. Для уровней f2-f6 используется 6 метрик:

**fX_t (Total)**
   Сколько серий физически достигло глубины X.
**fX_% (Market Share)**
   Какую долю рынка в свечах занимают серии данной длины.
**fX_g / fX_r**
   Кто больше раз довел серию до этого уровня (прямое сравнение).
**fX_g_% / fX_r_%**
   **Качественный индекс.** Процент зеленых/красных серий от ``fX_t``.
   Пример: если ``ch_g_%`` = 50%, а ``f6_g_%`` = 80%, быки эффективнее
   в удержании длительных движений.

Интерпретация данных (Пример 2026)
==================================

Анализ таймфрейма ``10080.csv``:
``ch_% = 46.05%``, ``p1_c = 55.56%``, ``p2_c = 47.27%``.

1. **Оценка хаоса**: Высокий ``ch_%`` говорит о нестабильности.
2. **Точка перелома**: Шанс продолжения падает ниже 50% на шаге 2 -> 3.
3. **Вывод**: Данный таймфрейм склонен к коротким всплескам по 2 свечи.
4. **Торговое решение**: Вход на 1-й свече, обязательный выход на 2-й.

.. tip::
   Сравнивайте ``fX_g_%`` и ``fX_r_%`` для определения скрытого
   преимущества одной из сторон при торговле на отскок.
