# ПОЛНЫЙ КАТАЛОГ СТАТИСТИК ДЛЯ АНАЛИЗА СМЕНЫ ТРЕНДА
# Всего: 110 категорий с подробными описаниями

## РАЗДЕЛ I: ОСНОВНЫЕ СТАТИСТИКИ (1-25)

1. ОБЩАЯ СТАТИСТИКА
   - Всего свечей: общее количество свечей в анализируемом периоде
   - Всего переходов между свечами: N-1, где N - количество свечей
   - Количество смен тренда: сколько раз цвет свечи менялся
   - Процент смен тренда: отношение смен к общему числу переходов

2. СТАТИСТИКА ПО ТИПАМ СМЕН
   - Зелёная → Красная: количество переходов с зелёной на красную свечу
   - Красная → Зелёная: количество переходов с красной на зелёную свечу
   - Процентное соотношение: доля каждого типа от общего числа смен

3. СТАТИСТИКА ПОСЛЕДОВАТЕЛЬНОСТЕЙ
   - Максимальная серия зелёных свечей: наибольшее количество подряд идущих зелёных свечей
   - Максимальная серия красных свечей: наибольшее количество подряд идущих красных свечей
   - Средняя серия зелёных свечей: средняя длина последовательности зелёных свечей
   - Средняя серия красных свечей: средняя длина последовательности красных свечей
   - Всего серий зелёных свечей: сколько раз начиналась серия зелёных свечей
   - Всего серий красных свечей: сколько раз начиналась серия красных свечей

4. ВЕРОЯТНОСТНЫЙ АНАЛИЗ
   - Вероятность смены цвета: статистическая вероятность изменения цвета следующей свечи
   - Вероятность продолжения тренда: вероятность, что следующая свеча будет того же цвета
   - После зелёной свечи: условные вероятности для свечи, следующей за зелёной
   - После красной свечи: условные вероятности для свечи, следующей за красной

5. РАСПРЕДЕЛЕНИЕ ДЛИН СЕРИЙ
   - Распределение длин зелёных серий: частота встречаемости серий разной длины для зелёных свечей
   - Распределение длин красных серий: частота встречаемости серий разной длины для красных свечей
   - Процентное соотношение: доля серий каждой длины от общего числа серий

6. АНАЛИЗ ЧЕРЕДОВАНИЙ
   - Паттерны чередований: частота различных 4-свечных последовательностей
   - Идеальное чередование (З-К-З-К или К-З-К-З): полное чередование цветов
   - Двойки (З-З-К-К или К-К-З-З): серии по две свечи каждого цвета
   - Тройки+ зелёных (З-З-З-К): длинные зелёные серии, заканчивающиеся красной
   - Тройки+ красных (К-К-К-З): длинные красные серии, заканчивающиеся зелёной
   - Другие комбинации: все остальные паттерны

7. КОРРЕЛЯЦИЯ ДЛИН СЕРИЙ
   - После короткой зелёной серии (1-2 свечи): какова вероятность короткой/длинной красной серии
   - После длинной зелёной серии (3+ свечи): какова вероятность короткой/длинной красной серии
   - Зависимость длины следующей серии от длины текущей

8. СТАТИСТИКА ПО ОКНАМ
   - Анализ по временным окнам: разделение данных на отрезки по N свечей
   - Процент смен в каждом окне: как меняется активность смен во времени
   - Максимальное окно: окно с наибольшим процентом смен
   - Минимальное окно: окно с наименьшим процентом смен
   - Среднее по окнам: средний процент смен по всем окнам

9. МЕТРИКИ ПРЕДСКАЗУЕМОСТИ
   - Энтропия последовательности: мера неопределённости (в битах)
   - Коэффициент предсказуемости: насколько последовательность предсказуема
   - Марковская цепь 1-го порядка: матрица переходов между состояниями

10. СТАТИСТИКА ЭФФЕКТИВНОСТИ
    - Средний прирост в зелёной серии: среднее процентное изменение цены в зелёных сериях
    - Среднее падение в красной серии: среднее процентное изменение цены в красных сериях
    - Максимальный прирост в одной серии: наибольший рост в отдельной зелёной серии
    - Максимальное падение в одной серии: наибольшее падение в отдельной красной серии

11. АНАЛИЗ ЭКСТРЕМУМОВ
    - Самая длинная серия без смены: максимальное количество подряд идущих свечей одного цвета
    - Самая длинная череда смен: максимальное количество последовательных смен цвета
    - Максимальный период стабильности: наибольший отрезок с минимальным количеством смен
    - Максимальный период нестабильности: наибольший отрезок с максимальным количеством смен

12. СТАТИСТИКА ПО КЛАСТЕРАМ
    - Низкая волатильность (<40% смен): доля времени в низкоактивном состоянии
    - Средняя волатильность (40-60% смен): доля времени в среднеактивном состоянии
    - Высокая волатильность (>60% смен): доля времени в высокоактивном состоянии

13. ТЕСТЫ НА СЛУЧАЙНОСТЬ
    - Тест серий (Runs test): проверка на случайность последовательности
    - Автокорреляция 1 лаг: корреляция между соседними свечами
    - Тест на независимость: проверка независимости событий
    - p-value: статистическая значимость результатов

14. ПРАКТИЧЕСКИЕ ВЫВОДЫ
    - Торговые инсайты: практические наблюдения для трейдинга
    - Эффективные паттерны: наиболее предсказуемые последовательности
    - Рисковые ситуации: условия с повышенной неопределённостью

15. ВРЕМЕННЫЕ ЗАВИСИМОСТИ
    - Цикличность по дням недели: активность смен по дням
    - Сезонность: изменения в разные периоды года
    - Внутридневные паттерны: изменение активности в течение дня

16. КЛАССИФИКАЦИЯ ПО ВОЛАТИЛЬНОСТИ
    - Классификация серий по величине движения: низкая/средняя/высокая волатильность
    - Корреляция волатильность/длина: связь между длиной серии и амплитудой движения

17. ПРОФИЛЬ РИСКА
    - Распределение убытков/прибылей: статистика по величине движений
    - Медианная прибыль в зелёной серии: типичный прирост
    - Медианный убыток в красной серии: типичное падение
    - Перцентили: распределение экстремальных значений
    - Соотношение риск/прибыль: баланс между потенциальными потерями и доходами

18. ТЕМПОРАЛЬНЫЕ ПАТТЕРНЫ
    - Изменение статистики во времени: эволюция параметров
    - Тренд изменения: направление изменения активности смен
    - Сезонность: повторяющиеся паттерны в разные периоды

19. КЛАСТЕРИЗАЦИЯ ПО ДЛИНЕ
    - Кластеризация паттернов по длине серий
    - Короткие чередования: частые смены
    - Средние серии: умеренные последовательности
    - Длинные серии: продолжительные тренды
    - Смешанные паттерны: комбинации разных длин

20. ПРЕДИКТИВНЫЕ МЕТРИКИ
    - Эффективность простых стратегий: успешность базовых торговых подходов
    - Стратегия "покупай после 2 красных": контртрендовая тактика
    - Стратегия "продавай после 2 зелёных": контртрендовая тактика
    - Стратегия "контртренд": игра против текущего движения
    - Стратегия "трендфолловинг": следование тренду

21. ГЕОМЕТРИЧЕСКИЙ АНАЛИЗ
    - Фрактальные характеристики: самоподобие структуры
    - Хёрстовский показатель: мера персистентности
    - Память процесса: насколько прошлое влияет на будущее
    - Длины циклов: характерные периоды повторений

22. СТАТИСТИКА ПО ГАПАМ
    - Анализ разрывов между сериями
    - Средний гэп между сменами: типичное расстояние между изменениями цвета
    - Максимальный гэп: наибольший промежуток без смен
    - Минимальный гэп: наименьший промежуток между сменами
    - Распределение гэпов: характер распределения интервалов

23. КОРРЕЛЯЦИЯ С ОБЪЕМОМ
    - Зависимость от объёма торгов: как объём влияет на частоту смен
    - Высокий объём: статистика при повышенной активности
    - Средний объём: статистика при нормальной активности
    - Низкий объём: статистика при пониженной активности
    - Корреляция объём/волатильность: связь между объёмом и амплитудой движений

24. МНОГОШАГОВЫЕ ПЕРЕХОДЫ
    - Вероятности на 2-3 шага вперёд: условные вероятности для более длинных последовательностей
    - Двухшаговые переходы: вероятности после двух определённых свечей
    - Трёхшаговые переходы: вероятности после трёх определённых свечей
    - Паттерны из 3 свечей: статистика для конкретных триплетов

25. СТАТИСТИКА ЭКСТРЕМАЛЬНЫХ СОБЫТИЙ
    - Хвостовые события: статистика редких, но значимых событий
    - Самые длинные серии: топ-5% по длине
    - Самые частые смены: топ-5% по активности
    - Black swan события: экстремально редкие события
    - Максимальная просадка: наибольшее падение в серии
    - Максимальный рост: наибольший рост в серии

## РАЗДЕЛ II: ПРОДВИНУТЫЕ СТАТИСТИКИ (26-50)

26. ТЕПЛОВЫЕ КАРТЫ ПЕРЕХОДОВ
    - Матрица переходов 3-го порядка: вероятности с учётом двух предыдущих свечей
    - Сложные паттерны: последовательности из 3+ свечей
    - Паттерны с памятью: зависимости от более далёкого прошлого

27. ЭНТРОПИЙНЫЙ АНАЛИЗ
    - Многомасштабная энтропия: энтропия на разных временных масштабах
    - Масштабный анализ: как сложность меняется с изменением масштаба
    - Снижение сложности: уменьшение энтропии на больших масштабах

28. ФАЗОВЫЕ ПЕРЕХОДЫ
    - Переходы между режимами: смена состояний рынка
    - Флет → Тренд: переход от консолидации к направленному движению
    - Тренд → Флет: переход от направленного движения к консолидации
    - Критические точки: пороговые значения параметров

29. НЕЛИНЕЙНАЯ ДИНАМИКА
    - Признаки хаоса: показатели детерминированного хаоса
    - Показатель Ляпунова: скорость расхождения траекторий
    - Корреляционная размерность: фрактальная размерность аттрактора
    - Рекуррентность: частота возвращений в похожие состояния
    - Детерминированность: степень предопределённости системы

30. СЕТЕВОЙ АНАЛИЗ
    - Граф переходов: сеть состояний и переходов между ними
    - Узлы: различные состояния системы
    - Рёбра: вероятности переходов между состояниями
    - Кластеризация: группировка похожих состояний
    - Центральность: наиболее влиятельные состояния

31. БАЙЕСОВСКАЯ СТАТИСТИКА
    - Апостериорные вероятности: вероятности с учётом наблюдаемых данных
    - Условные вероятности для сложных условий
    - Байесовский фактор: отношение правдоподобия гипотез
    - Обновление убеждений: как меняются вероятности с поступлением новых данных

32. МАШИННОЕ ОБУЧЕНИЕ
    - Предсказательная сила признаков: какие параметры лучше предсказывают смены
    - AUC (Area Under Curve): показатель качества классификации
    - Важность признаков: ранжирование параметров по значимости
    - Комбинированная модель: совокупная предсказательная способность

33. ПСИХОФИЗИЧЕСКИЕ МЕТРИКИ
    - Восприятие тренда трейдерами: как люди воспринимают изменения
    - Порог обнаружения тренда: минимальное количество свечей для распознавания тренда
    - Иллюзия тренда: ложное восприятие тренда
    - Эффект якоря: влияние предыдущих экстремумов
    - Постпринятийный диссонанс: психологические эффекты после принятия решений

34. ФИНАНСОВАЯ ТЕРМОДИНАМИКА
    - Энергетические метрики: аналогии с физическими системами
    - "Температура" рынка: мера активности
    - "Энтальпия": потенциал для движения
    - "Энтропийная сила": движущая сила изменений
    - Фазовые переходы: качественные изменения состояния

35. ГЕНОМНЫЙ АНАЛИЗ
    - Последовательности как ДНК: аналогии с генетическим кодом
    - "Гены" паттернов: элементарные строительные блоки
    - "Мутации": случайные изменения паттернов
    - "Наследственность": повторение паттернов
    - "Эволюция": изменение паттернов во времени

36. КВАНТОВЫЕ АНАЛОГИИ
    - Вероятностные характеристики: аналогии с квантовой механикой
    - Суперпозиция состояний: одновременное существование нескольких возможностей
    - Квантовая запутанность: корреляция между далёкими событиями
    - Принцип неопределённости: компромисс между точностью измерений
    - Коллапс волновой функции: переход от вероятностей к определённости

37. НЕЙРОННЫЕ ПАТТЕРНЫ
    - Аналогии с мозгом: сравнение с нейронными сетями
    - "Нейроны": элементарные единицы информации
    - "Синапсы": связи между элементами
    - "Пластичность": способность к изменению
    - "Эпилептические припадки": экстремальные события

38. ГЕОМЕТРИЯ ФРАКТАЛОВ
    - Самоподобные структуры: повторение паттернов на разных масштабах
    - Фрактальная размерность: мера сложности структуры
    - Скейлинг отношение: коэффициент масштабирования
    - Мультифрактальный спектр: распределение фрактальных размерностей

39. ТЕОРИЯ ИГР
    - Стратегические взаимодействия: моделирование поведения участников
    - Игра быков vs медведей: противостояние двух групп
    - Доминирующая стратегия: оптимальное поведение
    - Nash equilibrium: состояние, где никто не может улучшить свой результат
    - Кооперативные паттерны: совместные действия участников

40. КОГНИТИВНЫЕ ИСКАЖЕНИЯ
    - Систематические ошибки восприятия: предсказуемые отклонения от рациональности
    - Эвристика доступности: влияние легко вспоминаемых примеров
    - Эффект обрамления: влияние формулировки на восприятие
    - Иллюзия контроля: переоценка своей способности влиять на события
    - Предвзятость подтверждения: поиск подтверждений своим убеждениям

41. СОЦИАЛЬНАЯ ДИНАМИКА
    - Эффекты толпы: коллективное поведение участников
    - Социальное заражение: распространение настроений
    - Информационные каскады: цепные реакции принятия решений
    - Паник-selling: массовая распродажа
    - FOMO-buying: покупки из страха упустить выгоду

42. БИОЛОГИЧЕСКИЕ РИТМЫ
    - Циркадные ритмы: суточные циклы
    - Ультрадианные ритмы: циклы короче суток
    - Сезонные изменения: годовые циклы
    - 90-минутные циклы: базовые ритмы активности

43. КЛИМАТОЛОГИЧЕСКИЕ АНАЛОГИИ
    - Погодные паттерны рынка: сравнение с метеорологическими явлениями
    - "Солнечно": бычий тренд
    - "Облачно": флет
    - "Дождливо": медвежий тренд
    - "Штормовые предупреждения": высокая волатильность

44. ТОПОЛОГИЧЕСКИЙ АНАЛИЗ
    - Пространственные характеристики: свойства формы данных
    - Число Бетти: количество дыр разной размерности
    - Устойчивые гомологии: инварианты формы
    - Персистентные диаграммы: визуализация топологических особенностей
    - Топологическая сложность: мера структурной сложности

45. СЕМИОТИЧЕСКИЙ АНАЛИЗ
    - Язык рынка: изучение знаков и символов
    - "Слова": элементарные паттерны
    - "Грамматика": правила сочетания паттернов
    - "Синтаксис": структура последовательностей
    - "Семантика": значения движений
    - Информационная плотность: количество информации на единицу данных

46. ЭКОЛОГИЧЕСКИЕ МОДЕЛИ
    - Популяционная динамика: аналогии с биологическими популяциями
    - "Хищники" (медведи): продавцы
    - "Жертвы" (быки): покупатели
    - Циклы Лотки-Вольтерры: колебания численности
    - Каскады вымирания: цепные реакции изменений

47. АРХЕТИПИЧЕСКИЕ ПАТТЕРНЫ
    - Юнгианские архетипы: универсальные символические образы
    - "Герой": сильный тренд
    - "Мудрец": флет
    - "Тень": разворот
    - "Трикстер": ложный пробой

48. МУЗЫКАЛЬНЫЙ АНАЛИЗ
    - Ритмические паттерны: аналогии с музыкой
    - Темп: скорость изменений
